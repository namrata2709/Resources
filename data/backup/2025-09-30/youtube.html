4 Cloud Deployment Models

☁️ Public Cloud

Shared infrastructure, AWS/Azure/GCP

Use for: Web apps, startups, scalability

🏢 Private Cloud

Dedicated, single organization

Use for: Banks, healthcare, compliance

🔀 Hybrid Cloud

Combines public + private

Use for: Sensitive data + scalability

🏘️ Community Cloud

Shared by similar organizations

Use for: Universities, research

🤝 Shared Responsibility Model

AWS Responsibility

"Security OF the Cloud"

  • 🏢 Physical data centers
  • 🖥️ Hardware infrastructure
  • 🌐 Network infrastructure
  • 💫 Hypervisor (virtualization)
  • 🌍 Regions & Availability Zones

Your Responsibility

"Security IN the Cloud"

  • 🔒 Your data & encryption
  • 💻 Applications & code
  • 🔑 Access control (IAM)
  • 🛡️ OS patches (IaaS)
  • 🔥 Security Groups & firewalls

🎯 Remember: You are ALWAYS responsible for data and access control!

💫 What is Virtualization?

Virtualization: Technology that allows multiple virtual machines to run on a single physical server

❌ Before

  • 1 Server = 1 OS = 1 App
  • 15% utilization
  • 85% wasted!
  • Need 100 apps? Buy 100 servers

✅ After

  • 1 Server = 10 VMs = 10 Apps
  • 70% utilization
  • Efficient!
  • Need 100 apps? 10 servers with 100 VMs

Result: 80% reduction in hardware, power, and space costs!

How Virtualization Works

Layer 3: Virtual Machines

VM1: Windows | VM2: Linux | VM3: Ubuntu

Each with own OS, isolated from others

Layer 2: Hypervisor

Manages resources, maintains isolation

AWS uses: Nitro System

Layer 1: Physical Hardware

32 CPU cores | 256 GB RAM | 4 TB Storage

Type 1 vs Type 2 Hypervisors

Type 1: Bare Metal

Installed: Directly on hardware

Performance: ⚡ Best

Examples:

  • VMware ESXi
  • Microsoft Hyper-V
  • KVM, Xen
  • AWS Nitro System

Used in: Production clouds

Type 2: Hosted

Installed: On existing OS

Performance: 🐢 Good

Examples:

  • VirtualBox
  • VMware Workstation
  • Parallels

Used in: Development, testing

Why Cloud Providers Use Virtualization

  • Multi-Tenancy: Thousands of customers sharing infrastructure securely
  • Elastic Scaling: Launch VMs in 60 seconds (vs 3 weeks for physical)
  • Cost Efficiency: Share $1M server across 100 customers instead of 1
  • Rapid Provisioning: Create from templates (AMIs) instantly
  • Live Migration: Move VMs between hosts with zero downtime

This is why AWS can offer $0.10/hour pricing!

🎓 Key Exam Tips

💡 Public Cloud: Shared infrastructure, multi-tenant, pay-as-you-go. Examples: AWS, Azure, GCP.

💡 Service Models: IaaS = you patch OS | PaaS = AWS patches | SaaS = AWS manages all.

💡 Always Customer Responsibility: Data, encryption keys, access control (IAM), regardless of service model.

💡 Virtualization: Increases utilization from 10-15% to 60-80%. Type 1 hypervisors for production.

💡 AWS Nitro System: Custom hypervisor with near-bare-metal performance.

📝 Quick Recap

  • ✓ Deployment Models: Public (shared), Private (dedicated), Hybrid (both)
  • ✓ Service Models: IaaS (manage most), PaaS (just code), SaaS (just use)
  • ✓ Shared Responsibility: AWS secures infrastructure, you secure resources
  • ✓ Virtualization: Powers cloud through multi-tenancy and elastic scaling
  • ✓ Cost Savings: 80% hardware reduction via virtualization
