📖 The Business Story

The Problem:

Import-export business wants to go global → Needs digital presence → Must build app

The Challenge:

Building traditional IT infrastructure:

  • 💸 Huge upfront costs ($500K+)
  • ⏱️ Takes 6-12 weeks to set up
  • 📊 Servers run at 15-30% utilization (wasted $)
  • 🚫 Can't scale quickly during demand spikes

The Solution:

☁️ Cloud Computing: Zero upfront cost, instant scaling, pay only for what you use!

💻 How Computers Work

🧠 CPU

The brain - executes instructions

📝 RAM

Temporary memory - active workspace

💾 Storage

Permanent storage - filing cabinet

⌨️ Input

Keyboard, mouse - give commands

🖥️ Output

Monitor, speakers - see results

🌐 Network

Connect to other computers

💡 Cloud Connection: AWS EC2 = Virtual CPU + RAM, EBS = Virtual Storage

Programs vs Software vs Applications

Program

Specific set of instructions for ONE task

Example: Python script that prints "Hello World"

Software

Collection of programs packaged together

Example: MySQL database system (multiple programs)

Application

User-facing software with easy interface

Example: WhatsApp, Gmail - what YOU use daily

TermWho Uses ItExample
ProgramDevelopersCode script
SoftwareIT/ServersWeb server
ApplicationEnd UsersMobile app

⚔️ Waterfall vs Agile

🌊 Waterfall

  • Sequential & Rigid
  • Fixed requirements
  • 6-12 months to release
  • Testing at the end
  • Changes are difficult

❌ Slow, inflexible

🔄 Agile

  • Iterative & Flexible
  • Evolving requirements
  • Working software every 2 weeks
  • Continuous testing
  • Changes expected

✅ Fast, adaptive

Why Agile + Cloud = Perfect Match

Agile needs fast deployment → Cloud provides it in minutes!
Agile needs flexibility → Cloud scales instantly!
Agile needs testing environments → Cloud spins them up on-demand!

🖥️ Client-Server Architecture

🍽️ The Restaurant Analogy

RestaurantComputing
CustomerClient (your phone/laptop)
Places orderSends request
WaiterNetwork (internet)
KitchenServer (processes request)
Brings foodSends response

📱 Client REQUEST → 🌐 Network → 🖥️ Server PROCESSES → 🌐 Network → 📱 Client DISPLAYS

🏗️ Three-Tier Architecture

Tier 1: Presentation Layer

User interface - what you see

HTML, CSS, JavaScript, React

Tier 2: Application Layer

Business logic - processing

Node.js, Python, Java

Tier 3: Data Layer

Database - stores information

MySQL, PostgreSQL, MongoDB

Benefits: Separation of concerns • Independent scaling • Team specialization • Enhanced security

🌐 Networking Essentials

📍 IP Addresses

Unique identifier for devices

192.168.1.100

Public: Internet-accessible
Private: Internal networks

🚪 Ports

Service identifiers on servers

Port 22: SSH
Port 80: HTTP
Port 443: HTTPS
Port 3389: RDP

📡 Protocols

Communication rules

TCP: Reliable, ordered
UDP: Fast, no guarantee
HTTP/HTTPS: Web traffic

💡 Analogy: IP = Building address | Ports = Apartment numbers | Protocols = Language spoken

💰 CapEx vs OpEx

💸 CapEx (Capital Expenditure)

Large upfront investment

  • Buy servers: $500K+
  • Takes 6-12 weeks
  • Servers idle 70% of time
  • Sunk cost if needs change
  • Hard to scale

🚗 Like buying a car

💳 OpEx (Operational Expenditure)

Pay-as-you-go

  • Zero upfront cost
  • Ready in minutes
  • Pay only for usage
  • Stop paying anytime
  • Instant scaling

🚕 Like using Uber

Savings: Traditional $1.5M vs Cloud $950K over 5 years = $550K saved!

🔧 Service Models: IaaS, PaaS, SaaS

IaaS - Infrastructure as a Service

Provider: Hardware | You: OS, Apps, Data

Examples: EC2, Azure VMs

🏠 Like renting apartment - you furnish it

PaaS - Platform as a Service

Provider: Hardware + OS | You: Apps, Data

Examples: Elastic Beanstalk, Heroku

🏨 Like furnished apartment - just move in

SaaS - Software as a Service

Provider: Everything | You: Just use it

Examples: Gmail, Salesforce, Zoom

🏩 Like hotel - everything managed

Control vs Convenience: IaaS (Most Control) → PaaS (Balanced) → SaaS (Most Convenient)
