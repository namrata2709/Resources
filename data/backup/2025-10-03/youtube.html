What is MFA?

Multi-Factor Authentication

Two locks instead of one

🔑 Factor 1

Password

Something you KNOW

📱 Factor 2

One-Time Code

Something you HAVE

Why MFA Matters

❌ WITHOUT MFA:

Hacker steals password → Logs in → Launches 100 instances → $10,000 bill

✅ WITH MFA:

Hacker steals password → Can't log in (no phone) → BLOCKED

Result: Your account stays safe!

How MFA Login Works

  1. Enter email + password
  2. AWS validates credentials ✓
  3. AWS asks for MFA code
  4. Check phone → See 6-digit code (123456)
  5. Enter code → AWS verifies
  6. ✅ Access granted!

⏱️ Code changes every 30 seconds

What are Budget Alerts?

Budget Alerts

Spending limit notifications to prevent surprise bills

💵 Actual Cost

What you've spent SO FAR

Example: $30 on day 15

📊 Forecasted Cost

What AWS PREDICTS you'll spend

Example: $60 by month-end

Types of Budgets

💸 Zero Spend

Alerts at $0.01

For: Free Tier users

📅 Monthly Cost

Fixed limit (e.g., $50/month)

For: Budget control

📈 Usage

Track service hours/GB

For: Resource monitoring

💰 Savings Plans

RI/SP utilization

For: Enterprises

Budget Alert Flow

  1. AWS services generate costs
  2. Billing tracks usage every 6-8 hours
  3. Budget service monitors spending
  4. Threshold exceeded? → Alert triggered!
  5. 📧 Email sent to you
  6. You take action: stop resources, optimize
