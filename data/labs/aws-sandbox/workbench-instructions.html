🎯 Lab Overview

This is a sandbox environment for ad-hoc exploration of AWS services. This lab does not provide specific goals or steps like other labs. It is strongly recommended that you only create resources required to support your learning. All resources not in use should be either switched off or terminated.

📋 Prerequisites

This Sandbox lab requires:

  • Access to a notebook computer with Wi-Fi and Microsoft Windows, macOS, or Linux (Ubuntu, SuSE, or Red Hat)
  • An internet browser such as Chrome, Firefox, or Edge
📝 Note:

The lab environment is not accessible using an iPad or tablet device, but you can use these devices to access the student guide.

Task 2: SSH Access to any EC2 Instance(s) you launch

💡 Tip:

When launching EC2 instances in the sandbox environment, create an SSH key (.pem file) at the time of launch and download it. Then use that key to connect. The steps below describe how to use the SSH key to connect to your instance.

Windows Users: Using SSH to Connect

These instructions are specifically for Windows users. If you are using macOS or Linux, skip to the next section.

  1. Download PuTTY to SSH into the Amazon EC2 instance. If you do not have PuTTY installed on your computer, download it here.
  2. Open putty.exe
  3. Configure PuTTY timeout to keep the PuTTY session open for a longer period of time:
    • Select Connection
    • Set Seconds between keepalives to 30
  4. Configure your PuTTY session:
    • Select Session
    • Host Name (or IP address): Paste the Public DNS or IPv4 address of the instance you created.
    • Alternatively, return to the EC2 Console and select Instances. Check the box next to the instance you want to connect to and in the Description tab copy the IPv4 Public IP value.
  5. Back in PuTTY, in the Connection list, expand SSH
  6. Select Auth (don't expand it)
  7. Select Browse
  8. Browse to and select the lab#.ppk file used for the instance.
  9. Select Open to select it
  10. Select Open again.
  11. Select Yes, to trust and connect to the host.
  12. When prompted login as, enter: ec2-user
  13. This will connect you to the EC2 instance.
📝 Note:

For some flavors of linux the username may be different.

macOS and Linux Users

These instructions are specifically for Mac/Linux users.

  1. Open a terminal window, and change directory cd to the directory containing your Amazon EC2 instance *.pem file.

    For example, if your *.pem file was saved to your Downloads directory, run this command:

    cd ~/Downloads
  2. Change the permissions on the key to be read-only, by running this command:

    For example, if your *.pem file was labuser.pem

    chmod 400 labsuser.pem
  3. Run the below command (replace <public-ip> with the address of your Amazon EC2 instance).

    Alternatively, return to the EC2 Console and select Instances. Check the box next to the instance you want to connect to and in the Description tab copy the IPv4 Public IP value.

    ssh -i labsuser.pem ec2-user@<public-ip>
📝 Note:

Some flavors of Linux may use a different user to login.

  1. Type yes when prompted to allow the first connection to this remote SSH server.
  2. Because you are using a key pair for authentication, you will not be prompted for a password.
✅ Success!

You are now connected to your EC2 instance via SSH!
