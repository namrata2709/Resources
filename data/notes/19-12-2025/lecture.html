Why ECR exists

  1. Docker images must be stored somewhere
  2. AWS needs a secure, private registry
  3. Integrated with IAM & AWS services

Why “K8s” name?

K + 8 letters + s = Kubernetes

Kubernetes core terms (very basic)

  • Pod → smallest unit (container wrapper)
  • Node → machine running pods
  • Cluster → group of nodes

📌 Teaching line:
Kubernetes is cloud-agnostic. ECS is AWS-native.

Container Services – Final Summary

ECR (Elastic Container Registry)
→ Stores Docker container images in AWS

ECS (Elastic Container Service)
→ AWS-native service to manage and run containers

Fargate (AWS Fargate)
→ Serverless compute engine that runs containers without managing EC2 servers

Kubernetes (K8s)
→ Open-source, cloud-agnostic container orchestration platform

EKS (Elastic Kubernetes Service)
→ AWS-managed Kubernetes service
